# Exercises

Made-up practice material for the [tasks](../tasks.md), for those who don't have a suitable repo or safe data to work on. Everything here is fictional, so it is safe to use with a cloud-based agent.

| Folder | Task | What's in it |
|---|---|---|
| [a/](a/) | [A. Write tests](../tasks/a-write-tests.md) | A small Python module with no tests |
| [c/](c/) | [C. Explain something](../tasks/c-explain-something.md) | An Argo workflow to explain |
| [d/](d/) | [D. Review a workflow](../tasks/d-review-pr-or-workflow.md) | A GitHub workflow with security problems |
| [f/](f/) | [F. Decision paper](../tasks/f-notes-to-decision-paper.md) | Meeting notes with an open decision |
| [h/](h/) | [H. Tidy up a script](../tasks/h-tidy-up-old-script.md) | A messy extract script and a test file |
| [i/](i/) | [I. Validate XML](../tasks/i-validate-xml-extract.md) | A schema and an XML extract |
| [j/](j/) | [J. Readable SQL](../tasks/j-readable-sql-query.md) | An unreadable query and a test database |
| [k/](k/) | [K. Automate a task](../tasks/k-automate-recurring-task.md) | A folder of files with messy names |

Start the agent in the folder for your task. Use `git status` and `git diff` to see what it changed, and `git restore .` to start over.
